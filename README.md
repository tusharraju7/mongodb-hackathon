# mongodb-hackathon

MongoDB Hackathon.

Store local MongoDB connection settings in `.env`. This file is excluded from Git.

## Third-party development tools

Project-local agent skills in `.agents/skills/` are installed from
[langchain-ai/langchain-skills](https://github.com/langchain-ai/langchain-skills)
using the Agent Skills installer for Codex. These are upstream development
instructions, not original hackathon application code. `skills-lock.json`
records their source paths and content hashes.
